How it works Paste two fractional efficiency datasets at different face velocities. The tool fits each curve to Pierce's quadratic model (ln Pen = A(ln D)² + B ln D + C), back-calculates the velocity exponent N, and projects the penetration curve to the media velocity V4 computed by this calculator.
